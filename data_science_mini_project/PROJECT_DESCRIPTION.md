# Project Description

**Title:** Titanic Passenger Survival Analysis

**Problem Statement:** Analyze passenger demographics, socioeconomic indicators, and travel characteristics to identify patterns associated with survival during the Titanic disaster.

**Methodology:** Data loading → data understanding → missing-value treatment → feature engineering → exploratory data analysis → visualization → insight generation → conclusion.

**Outcome:** A reproducible Jupyter Notebook containing the complete analysis and visualizations.
